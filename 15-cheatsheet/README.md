# 15 — Cheatsheet

## Quotidiano
```bash
git status
git add .
git diff --staged
git commit -m "..."
git pull --ff-only
git push
```

## Branch
```bash
git branch
git switch -c feature/nome
git switch main
git merge feature/nome
```

## Diagnosi
```bash
git log --oneline --graph --decorate --all
git diff
git reflog
```
