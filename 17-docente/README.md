# Guida docente

## Metodo
Insegnare prima il modello mentale e poi la sintassi.

## Sequenza
1. repository
2. working tree
3. staging
4. commit
5. storia

## Domande di verifica
- Dove si trova il contenuto?
- Cosa entrerà nel prossimo commit?
- Qual è HEAD?
- Quale branch è attiva?
- Cosa è locale e cosa è remoto?

## Valutazione
Privilegiare comprensione, capacità diagnostica, sicurezza operativa e qualità dei commit.
