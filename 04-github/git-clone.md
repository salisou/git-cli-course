# git clone

## Cos'è
Crea una copia locale di un repository remoto.

## Sintassi
```bash
git clone <URL>
git clone <URL> <cartella>
```

## Esempio
```bash
git clone https://github.com/utente/progetto.git
cd progetto
git status
```

Dopo il clone verifica branch e remoti con git branch -a e git remote -v.
