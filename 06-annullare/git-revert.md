# git revert

## Cos'è
Crea un nuovo commit che annulla l'effetto di un commit precedente.

## Sintassi
~~~bash
git revert <commit>
~~~

## Perché usarlo
Su branch condivise consente di correggere il risultato senza riscrivere i commit esistenti.

## Esercizio
Crea un commit e annullalo con `git revert`.
