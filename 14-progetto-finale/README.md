# 14 — Progetto finale: Git Professional Team Workflow

Simulazione di un piccolo team software.

## Scenario
Branch: main, feature/login, feature/dashboard, feature/export.

## Deliverable
- repository inizializzata
- commit coerenti
- branch
- merge
- conflitto risolto
- pull request
- tag v1.0.0
- recovery con reflog
- relazione finale con i comandi utilizzati

Obiettivo: dimostrare comprensione del modello Git e capacità di recupero dagli errori.
