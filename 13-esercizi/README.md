# 13 — Esercizi

## Base
1. init, status, add, commit, log.
2. Modifica un file e osserva status e diff.

## Intermedio
1. Crea una feature branch.
2. Esegui merge.
3. Pubblica il branch.

## Avanzato
1. Simula un conflitto.
2. Risolvilo.
3. Recupera un commit con reflog.
4. Usa bisect su una regressione riproducibile.
