# git log

## Cos'è
Visualizza la cronologia dei commit.

## Sintassi
~~~bash
git log
git log --oneline
git log --graph --decorate --oneline --all
~~~

## Esempio
La vista grafica è utile per comprendere branch e merge.

## Ricerca
~~~bash
git log --author="Moussa"
git log --grep="login"
git log -- README.md
~~~

## Esercizio
Visualizza la storia in formato grafico compatto.
