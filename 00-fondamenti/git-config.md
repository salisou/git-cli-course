# git config

## Cos'è
Gestisce la configurazione di Git.

## A cosa serve
Configura identità, branch predefinito e comportamento dei comandi.

## Sintassi
~~~bash
git config --global user.name "Moussa Salisou"
git config --global user.email "email@example.com"
git config --global init.defaultBranch main
git config --list
~~~

## Esercizio
Configura nome, email e branch predefinito.

## Buone pratiche
Non inserire token, password o segreti nella configurazione pubblicata.
