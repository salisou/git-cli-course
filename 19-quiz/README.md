# Quiz finale Git CLI

## 1. Cosa contiene la staging area?
A. Repository remoto
B. Contenuto preparato per il prossimo commit
C. Solo file ignorati
D. Browser

**Risposta: B**

## 2. Quale comando crea un commit?
A. git add
B. git status
C. git commit
D. git fetch

**Risposta: C**

## 3. Quale comando scarica informazioni remote senza integrarle automaticamente?
A. git fetch
B. git commit
C. git revert
D. git tag

**Risposta: A**

## 4. Quale operazione riscrive la storia della branch interessata?
A. git status
B. git rebase
C. git fetch
D. git show

**Risposta: B**

## 5. Quale comando annulla un commit creando un nuovo commit?
A. git restore
B. git revert
C. git blame
D. git clone

**Risposta: B**

## 6. Quale strumento aiuta a recuperare riferimenti locali?
A. git reflog
B. git status
C. git remote
D. git mv

**Risposta: A**

## 7. Perché usare .gitignore?
A. Cancellare Git
B. Evitare il tracking di file selezionati
C. Creare branch
D. Fare merge

**Risposta: B**

## 8. Cosa fa git push?
A. Invia riferimenti e oggetti al remote
B. Cancella il repository locale
C. Crea sempre un merge
D. Modifica .gitignore

**Risposta: A**

Spiega la differenza tra restore, reset e revert e indica quale useresti in una branch condivisa per annullare pubblicamente una modifica.
