# git init

## Cos'è
Inizializza una nuova repository Git nella directory corrente.

## Sintassi
`git init [directory]`

## Esempio
```bash
mkdir progetto
cd progetto
git init
```

Git crea la directory nascosta `.git`, che contiene oggetti, riferimenti e metadati della repository.

## Errore comune
Eseguire `git init` nella cartella sbagliata. Controlla sempre `pwd` e `git status`.

## Esercizio
Crea una repository chiamata laboratorio-git.
