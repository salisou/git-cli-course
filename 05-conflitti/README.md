# 05 — Conflitti

Un conflitto nasce quando Git non riesce a integrare automaticamente modifiche incompatibili.

## Procedura
1. git status
2. aprire i file indicati
3. risolvere <<<<<<< ======= >>>>>>>
4. git add <file>
5. completare merge o rebase

Non risolvere un conflitto alla cieca: comprendere entrambe le modifiche.
