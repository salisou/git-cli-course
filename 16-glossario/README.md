# Glossario Git

| Termine | Significato |
|---|---|
| Repository | Archivio Git del progetto |
| Working tree | File presenti sul filesystem |
| Index | Staging area |
| Commit | Snapshot registrato |
| HEAD | Riferimento alla posizione corrente |
| Branch | Riferimento a una linea di sviluppo |
| Remote | Repository remoto nominato |
| Merge | Integrazione di storie |
| Rebase | Riapplicazione di commit sopra una nuova base |
| Tag | Riferimento per identificare una versione |
| Conflict | Modifiche non combinabili automaticamente |
| Stash | Modifiche temporaneamente accantonate |
| Reflog | Registro locale dei movimenti dei riferimenti |
| Upstream | Branch remoto associato |
| PR | Proposta di integrazione su GitHub |
