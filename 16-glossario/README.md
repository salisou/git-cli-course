# 16 — Glossario

- **Working tree**: file presenti nella cartella di lavoro.
- **Staging area**: area che prepara il prossimo commit.
- **Commit**: oggetto che registra una versione della storia.
- **HEAD**: riferimento alla posizione corrente.
- **Branch**: riferimento mobile a una linea di sviluppo.
- **Remote**: repository remoto associato.
- **Merge**: integrazione di linee di sviluppo.
- **Rebase**: ricostruzione dei commit su una nuova base.
- **Tag**: riferimento nominato, spesso usato per release.
